# 用法：每行一个 Modrinth 项目，格式为：
#     slug                 仅用 slug 直查（推荐，命中率最高）
#     slug|搜索关键词      slug 查不到时，用关键词搜索兜底
#                          （部分模组的 id 是连写的，如 explosiveenhancement，
#                            直接搜不到，需要补英文名 Explosive Enhancement）
#   # 开头为注释；新增模组加一行，剔除模组删一行即可。
#
# 已剔除及原因：
#   已内置到 mixinenhance 本体，无需独立模组：
#     fallingtree        -> 砍树整棵倒下（enableFallingTree）
#     diggusmaximus      -> 连锁挖矿（enableVeinMining）
#     freecam            -> 自由视角（enableFreeCam）
#   整合包不需要（地形与群系 / 建筑结构）：
#     terralith, tectonic, biomesoplenty, terrestria, nullscape, amplified_nether, cinderscapes,
#     repurposed_structures, ctov, dungeons_arise, mr_dungeons_andtaverns, additionalstructures,
