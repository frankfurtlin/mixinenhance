# 开发规范

本文档记录 mixinEnhance 项目开发中必须遵守的约定，供后续开发参考索引。

## 一、配置必须具有通用性

- 新增配置项前，先确认它控制的是「**一类通用机制**」，而不是「单个/少数特定实体」的行为。
- 一个配置应尽量只在**一处 Mixin** 生效，理想状态是「1 配置 → 1 处注入点」。
- 判断标准：如果新增一个配置需要同时改 N（N > 2）个 mixin 文件，说明它可能不够通用，应先收敛语义或拆分配置。

### 反面案例：attackMultiplier 的教训

`attackMultiplier` 最初试图用「一个旋钮」同时控制近战、远程、爆炸、独立实体等**完全不同的伤害机制**，导致散落在 10 个 mixin：

- 属性攻击：`MobEntityMixin`（统一入口，当时名为 `MobDifficultyMixin`）+ 史莱姆/幻翼/凋零骷髅 3 个动态属性特例
- 非属性伤害：骷髅弓箭、幻术师弓箭、溺尸三叉戟、唤魔者尖牙、潜影贝子弹、恶魂火球爆炸

每次 MC 升级，这 10 个注入点（方法名/常量/签名）都可能失效，维护成本极高。

**收敛结果**：`attackMultiplier` / `healthMultiplier` 最终都收敛为仅 `MobEntityMixin` 一处，通过属性系统（`MAX_HEALTH` / `ATTACK_DAMAGE`）对所有 `Enemy` 敌对生物统一缩放。远程/爆炸/独立实体伤害不再挂该配置，特殊生物的倍率覆盖也一并移除（它们有自身的属性动态重算机制，会自然恢复原版值）。

### 落地原则

- 优先复用「属性系统」等统一入口，而非为单个实体单独建 mixin。
- 特殊实体的例外处理应尽量避免；确有必要时，优先在统一入口里加 `instanceof` 判断，而不是新建独立 mixin。

## 二、配置必须同步多语言文件

每新增一个配置字段，必须**同步**在以下两个文件添加翻译，否则 ModMenu 界面会显示变量全名：

- `src/main/resources/assets/mixinenhance/lang/zh_cn.json`
- `src/main/resources/assets/mixinenhance/lang/en_us.json`

要点：

- key 格式：`text.autoconfig.mixinenhance.option.<模块路径>.<字段名>`
- tooltip 用 `...@Tooltip` 后缀
- `en_us.json` 惯例是直接以字段名作为译文（`category.*` / `key.*` / `message.*` 这类非配置项键写真实英文）

## 三、配置结构变更必须写迁移

- **改名 / 移动 / 删除配置字段**时：把 `ConfigMigrations.CURRENT_VERSION` +1，并在 `MIGRATIONS` 里加一条
  `fromVersion = 旧版本` 的迁移，负责把旧键搬到新键。否则 AutoConfig 只会按字段名读写，旧值会被静默丢弃、
  悄悄回到默认值。
- 迁移在 AutoConfig 读文件**之前**执行（见 `MixinEnhanceConfig.holder()`）。
- 迁移之外还会做一次失效键检查：把「配置文件里有、代码里没有」的键列进日志，方便用户知道哪些设置失效了。

## 四、注入点自检清单

- 新增或修改**带 `require = 0`** 的注入点后，必须重新生成清单：
  `python3 tools/gen_injection_manifest.py`。CI 与 pre-commit 会校验清单是否过期（`--check`）。
- 清单是启动时「注入自检」的数据来源：注入失配会出现在日志与 `/mixinenhance status` 里，
  而不是静默消失。清单由脚本扫描源码生成，不要手改。

## 五、新增快捷键

- 用 `HotkeyRegistry.register(...)` 注册，并把默认按键登记到 `HotkeyRegistry.defaultKeyOf`；
  它统一处理「配置项是总开关」「切换后提示」「配置关闭时收尾」这三件事。
- 想让配置界面显示当前按键：给对应配置字段加 `@HotkeyHint("<快捷键 id>")`。

## 六、其他约定

- 配置类位于 `src/main/java/com/frankfurtlin/mixinenhance/config/section/`，按模块拆分（General / Player / Block / Item / Entity / Enchant / Fishing）。
- 删除配置项时，需同步删除：配置字段、对应 Mixin 注入、`mixinenhance.mixins.json` 注册（若整个 mixin 删除）、两个语言文件中的翻译。
